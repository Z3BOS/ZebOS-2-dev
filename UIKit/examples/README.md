# UIKit examples

- **[component-gallery.html](component-gallery.html)** — open directly
  in a browser (no server, no JS build needed). A visual reference for
  every reusable class in UIKit: buttons, window frame, taskbar, start
  menu, list rows, form controls, icons.

- **[hello-app-framework.js](hello-app-framework.js)** — a minimal app
  built on [`../framework/`](../framework/). Start here — it's the
  shortest path to a working app.

- **[hello-app.js](hello-app.js)** — the exact same app, built by hand
  with no framework, for comparison / if you'd rather not use it.

None of these are wired into the desktop — copy whichever one into
`programs/` and follow [`../howto/new-app.md`](../howto/new-app.md) to
register it as a real, launchable app.
