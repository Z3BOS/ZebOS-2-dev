Icons

.sys-icon — real icons come from the code-based SVG set in icons.js (getIcon(name)); these two placeholders just demonstrate the sizing contract (square, viewBox="0 0 24 24").

18×18 base — grows to 38×38 inside .desktop-icon, shrinks to 16×16 inside .window-title / .taskbar-tab, automatically, via context selectors in desktop.css.
