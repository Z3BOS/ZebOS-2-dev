# ZebOS 2 Pro

> An open-source, unofficial variant of **ZebOS 2** built directly on top of 7Zeb's official Pre-Alpha release.

---

## 📌 Overview

**ZebOS 2 Pro** is an open-source project developed by **Adurite / Adurite Designs**. Rather than continuing the unreleased design concept seen in *ZebOS 2 Preview* (previously featured on 7Zeb's YouTube channel), ZebOS 2 Pro focuses on expanding 7Zeb's actual **ZebOS 2 Pre-Alpha** build.

This repository serves as an enhanced, worked-upon edition of the Pre-Alpha system, adding new functionality, refined code implementations, and feature experiments.

---

## Resemblance to The Official ZebOS 2

* **Upstream Reference:** ZebOS 2 Pro is built directly on 7Zeb's JavaScript OS base.
* **Open-Source Resource:** This project is fully open-source so **7Zeb** can review implementations, test experimental code, or port select features and logic into the official ZebOS 2 repository.
* **Unofficial Release:** Features developed here are experimental and are not guaranteed to be merged into the official release unless chosen by 7Zeb.
